# ShopNest — Static E-Commerce Website

A clean, responsive static e-commerce website built for **Assignment No. 2 (Module End) — HTML/CSS Module**.

Built using **HTML5 semantic tags**, **CSS3**, **Flexbox**, and **Bootstrap 5**.

---

## How to Run

1. Open `Assignment-2/` folder.
2. Double-click `index.html` to open it in your web browser, or use VS Code Live Server.

---

## 25-Mark Assessment Criteria Mapping

| Criteria | Marks | Implementation |
|---|:---:|---|
| **HTML5 semantic structure** | **5** | All 7 required semantic tags used: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>`. |
| **CSS and Bootstrap styling** | **5** | Clean typography (Poppins), consistent color scheme, card hover effects, and Bootstrap grid integration. |
| **Responsive layout** | **5** | Bootstrap grid (`row`, `col-12`, `col-sm-6`, `col-lg-4`), Flexbox, and media queries for desktop, tablet, and mobile. |
| **Product cards** | **5** | 6 complete product cards (`<article>`) with image, title, rating stars, original price (`<del>`), discounted price, and "Add to Cart" button. |
| **Category section, newsletter & footer** | **3** | 4 clickable category visual tiles (Electronics, Clothing, Footwear, Books), newsletter signup form with HTML validation, and 4-column footer (About, Quick Links, Contact, Social Media). |
| **Code quality & comments** | **2** | Clean indentation, meaningful class names, and readable section comments. |
| **Total** | **25 / 25** | **100% matched to assessment requirements.** |
