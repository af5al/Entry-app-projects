# FashionHub homepage

Responsive recreation of the supplied FashionHub homepage using HTML5, CSS3, Bootstrap 5 grid and Flexbox.

## Run
Extract the ZIP and open `index.html` in a browser. Bootstrap and Google Fonts load from CDNs; all supplied product/category/hero images are stored locally in `assets/`.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `assets/` — supplied Figma reference images
